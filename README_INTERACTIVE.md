# 🎭 交互式演示 - 去中心化加密聊天

## 🎯 完美适合课程演示！

这是一个**可以实际运行**的去中心化安全聊天系统，专为课程演示设计：

- ✅ **三个终端窗口** - 同一台电脑运行
- ✅ **实时手动输入** - 像真实聊天一样
- ✅ **安全性可视化** - 窃听者无法破解
- ✅ **5分钟搞定** - 快速启动和演示

## 🚀 三步启动

### 1. 打开三个终端窗口

```bash
# 窗口1 - Alice (合法用户)
npm run alice

# 窗口2 - Bob (合法用户)
npm run bob

# 窗口3 - Eve (窃听者/攻击者)
npm run eve
```

### 2. 等待连接（约5秒）

所有窗口显示 `✅ 就绪！当前连接数: 2`

### 3. 开始聊天！

**Alice 窗口:**
```
Alice> 你好Bob！
```

**Bob 窗口会显示:**
```
💬 [15:30:45] Alice: 你好Bob！
```

**Eve 窗口会显示:**
```
🕵️  [监听 #1] 截获加密消息！
   加密内容: maggYmEM+QDcBhlaPCyS7...

🔓 尝试破解...
   ✗ 密钥1 解密失败
   ✗ 密钥2 解密失败
   ✗ 密钥3 解密失败

❌ 破解失败！无法解密消息内容。
```

## 🎬 演示流程建议

### 第1幕：启动系统
1. 打开三个终端窗口
2. 依次启动 Alice, Bob, Eve
3. 解释：*"Alice 和 Bob 是合法用户，Eve 是窃听者"*

### 第2幕：正常通信
4. Alice 发送：`你好Bob！`
5. 观察 Bob 收到解密消息
6. 观察 Eve **看到加密内容但无法解密**

### 第3幕：多轮对话
7. Bob 回复：`你好Alice！`
8. Alice 发送：`今天天气不错`
9. 每条消息 Eve 都破解失败

### 第4幕：展示统计
10. 在 Eve 窗口输入 `stats`
11. 显示：*"截获 N 条消息，破解成功 0 次 (0%)"*
12. 强调：*"这就是端到端加密的威力！"*

## 💡 演示时的讲解要点

### 技术亮点1: P2P 网络
```
"注意看，三个程序启动后自动发现彼此。
没有中心服务器，完全是点对点连接。
使用了 Hyperswarm 的 DHT 技术。"
```

### 技术亮点2: 加密安全
```
"Alice 和 Bob 使用 NaCl 加密库，
每条消息都用 XSalsa20-Poly1305 算法加密。
Eve 虽然能监听网络流量，
但没有密钥就完全无法破解。"
```

### 技术亮点3: 实时性
```
"消息发送几乎是即时的，
这展示了 P2P 网络的高效性。
不需要经过中心服务器的转发。"
```

## 📊 技术栈说明

### 网络层
- **Hyperswarm** - 现代 P2P 框架
- **DHT** - 分布式哈希表节点发现
- **NAT穿透** - 自动处理防火墙

### 加密层
- **Scrypt** - 密钥派生函数
- **NaCl/TweetNaCl** - 加密库
- **XSalsa20-Poly1305** - 对称加密算法

### 应用层
- **Node.js** - 运行环境
- **Readline** - 交互式输入
