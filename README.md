# 去中心化安全社交网络

基于 Hyperswarm 的 P2P 加密聊天系统 - 计算机网络课程项目

## 🎯 项目简介

这是一个完整的去中心化安全社交网络系统，实现了：
- ✅ P2P 节点自动发现（无需中心服务器）
- ✅ 端到端加密通信（第三方无法破解）
- ✅ 实时消息传输（毫秒级延迟）
- ✅ 窃听者无法解密演示（安全性可视化）

## 📦 技术栈

- **网络层**: Hyperswarm (DHT + NAT穿透)
- **加密层**: Scrypt (密钥派生) + NaCl (端到端加密)
- **运行环境**: Node.js + ES Modules

## 🚀 快速开始（3步搞定）

### 1. 安装依赖

```bash
npm install
```

### 2. 打开三个终端窗口

**终端1 - Alice (合法用户):**
```bash
npm run alice
```

**终端2 - Bob (合法用户):**
```bash
npm run bob
```

**终端3 - Eve (窃听者):**
```bash
npm run eve
```

### 3. 等待连接（约5秒）

看到 `✅ 就绪！当前连接数: 2` 后即可开始聊天。

## 🔧 常见问题

### Q: 连接数为 0 怎么办？
A: 等待更长时间（10-15秒），DHT 发现需要时间。

### Q: Eve 能解密消息？
A: 检查所有客户端是否使用了正确的密钥配置。

### Q: 可以在两台电脑上运行吗？
A: 可以！Hyperswarm 自动处理 NAT 穿透。

### Q: 如何退出程序？
A: 输入 `exit` 或按 `Ctrl+C`。
